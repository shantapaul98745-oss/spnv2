### 2.20 优先开题诊断：Offline 可靠性信号能否预测 ODR 后的样本退化

来源：用户 2026-10-18 关于直接使用官方 pretrained SPNv2、先分析可靠性再设计适应算法的建议。**值得记录为优先前置诊断，关联 003、004、009，不独立新增创新编号。** 本节形成待执行方案；未下载或切换权重、未运行 ODR 或新训练。

**（1）研究定位。** 将 SPNv2 作为“已有多任务 source 模型＋固定、简单的分割熵适应基线”：复用多尺度共享特征、直接位姿回归、关键点/PnP、分割输出及已有 source 训练资产，优先研究这些信号能否提供有用的适应风险信息。无需为了建立这一诊断先重训或改造网络。“强 source model”是研究中的基座定位，具体 checkpoint 在目标域的实际性能仍须报告，不能预设已经足够准确。

可优先采用官方发布的 **source/offline checkpoint**，启动前确认下载来源、版本与哈希、BN/GN 配置、预测头完整性及预处理兼容性，避免误用已在目标域适应的权重。官方权重与本地复现权重分开记录，不能以其中一个作 before、另一个作 after；是否已具备匹配的官方资产待执行前核实。现有本地 source 权重可作为独立复核条件，无需为本项诊断先重做 source 训练。

**（2）先固定 Offline 状态，记录原始信号。** 每个目标图像在同一个未适应模型 \(\theta_0\) 上预测，保存图像 ID、域及以下量；先单独分析，再决定是否有依据构造综合 \(r(x_i)\)，不预先把不同量纲相加。

| 记录项 | 定义与必要说明 |
|---|---|
| Segmentation entropy | 明确是原 ODR 单项 \(-p\log p\) 还是完整二元熵；可同时记录，分别命名，固定空间 reduction，不更改适应损失 |
| Heatmap peak confidence | 保存关键点峰值及预先规定的聚合量，如均值、低分位数或有效关键点比例；避免事后挑最有利的统计 |
| PnP reprojection residual | 固定像素/归一化单位及点集口径，说明是在全部预测点还是求解内点上计算 |
| \(E_R(R_E,R_H)\) | 两条预测分支之间的旋转分歧；统一旋转约定、单位，区别于相对 GT 的旋转误差 |
| \(\|t_E-t_H\|\) | 两分支平移差；统一坐标和尺度，若归一化，分母仅使用部署时可得信息 |
| PnP reject 状态 | 记录求解失败、关键点不足等原因；无有效位姿时相关分歧/残差记为缺失，不填零或只留下成功样本 |

这些部署可计算信号与 GT 评价列分别存储。Offline 预测和信号提取应保持模型状态固定，避免 BN 统计因额外前向变化。未来在线门控通常使用当前适应状态 \(\theta_t\)，因此本轮 \(r(x_i;\theta_0)\) 的结论不能自动推广为整个适应过程中的判据稳定性。

**（3）原始 ODR 与配对评价。** 预先固定 ODR 代码版本、学习率、B/N、目标观测顺序及多个观测流 seed；每次从同一 Offline 权重和初始更新状态独立开始。原样实现与 BN 等修复线分开标记，所有配对结果使用同一基础版本。预算与超参数不得为本次结论反复按最终目标测试标签挑选。

按用户提议，首轮采用“完成一次固定预算 Original ODR → 评价同一图像清单”的低成本诊断协议。这里 after 指整轮 ODR 之后的模型，不是每张图像分别重置模型再更新。使用仅供科研评价的 GT 计算：

\[
\Delta E_i=E_i^{\mathrm{after}}-E_i^{\mathrm{before}},\qquad
z_i=\mathbf1[\Delta E_i>0].
\]

固定主要位姿分支和同一种误差指标，保留严格退化定义；如另报实际容忍量 \(\delta_{\mathrm{deg}}\)，预先确定并单列。按 ID 对齐 before/after，全图像清单均保留；数值差在共同有效集上计算，同时报告覆盖率、有效→无效及无效→有效。记录评价图像是否参与适应及其在观测流中的位置，披露适应集与评价集是否重合。该结果不冒充第 2.18 节的严格因果在线累计表现。

**本实验直接回答：\(r(x_i;\theta_0)\) 能否识别“经过这一 ODR 协议后更容易退化的评价图像”？** 它尚不能回答“将 \(x_i\) 用于更新是否有益”：图像 \(i\) 的误差变化可能由整条适应流中的其他图像更新造成，评价图像也可能根本没有参与更新。若之后逐图重置并更新自身，则属于另一种单图适应诊断，同样不能代替后续帧收益或样本选择的因果验证。

**（4）优先分析什么。** 将各几何信号与分割熵作同口径比较，分别分析 lightbox、sunlamp 以及配对观测流种子，关注是否存在超出熵置信度的风险信息。相关性只作为辅助，同时检查按信号分组后的退化率、风险排序、风险—覆盖关系及高风险尾部；使用 AUROC/AUPRC 时声明分数方向、退化事件比例与比较基线。少量种子或一个域的偶然趋势不足以作为门控有效的结论。

\(\Delta E\) 含有 \(E^{\mathrm{before}}\)，信号也可能主要反映初始预测难度，因此事后按 Offline 误差分层，检查是否仍有风险区分能力，避免将初始难度、改善空间或回归均值误认为更新风险机制。这里使用 GT 的分层仅是解释性分析，不能作为部署时筛选输入。PnP reject 和缺失信号作为单独组分析，不能通过删掉失败图像获得表面相关。

**（5）GT 的边界与去留标准。** 对预先固定的信号作事后风险评价可以使用 GT；但若看过这些结果后选择信号、拟合 \(r\)、调整组合或阈值，这部分数据就承担了开发用途。最终主张须在未参与选择的留出图像/观测流上确认，不能一边利用最终 HIL 测试标签优化判据，一边声称整个选择过程无目标标签。划分与信息来源提前声明；仅更换 seed 而继续使用相同已调参图像，不自动形成独立验证集。

若信号在独立确认中显示可重复的排序或风险分组能力、并超出熵信号，可进入 003 的实际门控干预及匹配预算对照。若当前信号没有稳定识别能力，应先修订指标或分析失败条件，暂缓复杂适应算法。**弱线性相关不足以否定所有几何判据；明显相关也不足以证明门控有效。** 阈值、最低有用识别能力及不确定性报告方式在开发阶段冻结，不事后设定“显著”的标准。

**（6）交付物与联动。** 预期产出为一份按图像 ID 对齐的信号—误差配对表，以及两域、多 seed 的单信号风险分析、缺失/失效统计和相对熵基线的比较；它为是否投入门控实现提供证据。建议顺序为：**P0 权重与协议确认 → P1 本节静态退化诊断 → 003 门控干预 → 必要时补充同一模型状态下纳入/不纳入某样本的受控更新诊断 → 按证据推进 011 伪监督与 005 safeguard。** 004 的更新前后信号变化、009 的代理失效研究可在后续衔接，但不把本实验提前写成已经证明“这次更新值不值得做”。
