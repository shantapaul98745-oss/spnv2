## 2. 首轮要回答的问题

## 5. 门控规则与状态处理

G对当前图像使用当前模型更新前的预测。首版只采用固定、可解释的评分，不训练新的评分网络。

| 信号 | 定义 | 可靠方向 |
|---|---|---|
| 热图置信度C | 11个关键点热图峰值的第25百分位；不把未经校准的峰值称为概率 | 大 |
| 重投影残差R | 既有PnP姿态投影与预测2D关键点的残差，统一坐标后按图像对角线归一；包含全部可用的11点，不仅用拟合内点 | 小 |
| 双头旋转分歧Q | hE旋转与hH/PnP旋转的测地角差，固定单位 | 小 |
| 双头平移分歧T | 两预测平移的欧氏差除以预测距离尺度；采用两预测距离均值与固定数值保护，不使用GT距离 | 小 |

**共同校准默认：** 两域开发图像在同一固定source状态下产生预测，合并校准一套分位映射；两域共用映射、组合规则和阈值。同一信号先变为“越大越可靠”的经验分位分数，组合分数取四项的最小值。

比较两档阈值：在可合法打分的开发图像上，分别以约50%、75%的目标接受率确定合成分数的阈值。应对合成分数取分位阈值，不能直接把min分数≥0.5/0.75解释为接受50%/75%。

拟固定经验分位映射的并列值处理、线性分位插值及“分数≥阈值即接受”；其定义写入配置和审计。PnP或必要预测不合法时始终拒绝更新，不为凑接受率放宽合法性。阈值在source开发预测上定好后，在适应期间保持固定；当前模型会变化，实际接受率可以偏离50%/75%，且两域分别报告。不能利用整条未来流排名选top-K。

**状态边界：**

- 门控评分不反传，评分前向不额外改变参数、BN运行统计/计数、模式、优化器、已有梯度、手工统计缓存、随机状态或数据流位置。
- 接受图像按原A损失及状态规则贡献更新；每累计4张接受图像提交一次完整窗口。
- 拒绝图像不贡献更新梯度或归一化统计，但保留正常预测，仍进入评价。
- 不足4张的尾部不提交更新，丢弃未提交的梯度/统计，并记录接受数、实际用图数与尾部数。若该尾部前向已经改变BN等状态，应恢复至最后完整窗口边界，不能只清梯度却留下尾部状态变化；所有门控对照采用同一尾部规则。
- 保留原A的模式及统计行为，不顺带修成B2；归一化处理改变属于独立研究因素。
- “全部接受”分支必须与原A核对样本流、逐图输出/有效性、更新次数、参数/统计和完整状态；评分前向造成的污染属于实现失败。

| 组 | 内容 | 作用 |
|---|---|---|
| O | Offline，不适应 | 同一source的固定误差/风险参照 |
| A | 冻结的原样ODR，全部观测参与原规则更新 | 003主要基线 |
| E50/E75 | 分割熵置信度门控，两档源于开发预测的接受阈值 | 检查普通置信度筛选 |
| V | 仅原有PnP合法性及必要有限性检查，不加质量阈值 | 检查基本有效性筛选 |
| G50/G75 | 组合几何门控，两档阈值 | 003候选 |
| R | 与选定G匹配实际完整更新用图数的随机门控 | 排除仅仅少更新的解释 |

E可以用完整二元熵作为评分信号；其反向更新仍使用原A损失。不能将008的熵目标替换混入003。G与V的基本可计算性规则在实现前写成同一规则清单，额外不可计算原因单独计数。

**第一步：固定基础探索。**
- O每域一次，可复用同次source预测进行无标签评分校准与开发评价。
- A、V、E50、E75、G50、G75，共6种运行设置。
- 2域×3条流×6设置＝36次正式预算ODR探索运行。
- 每次观察N1024，随后只评价开发GT集。

**第二步：有合格趋势后，补随机预算对照。**
- 按第8节规则选出一档共同G阈值，不为每域挑不同阈值。
- 对每域每流，令M=4×floor(G实际接受数/4)。
- R从同一完整输入流中随机选择M张，保留原顺序，匹配G的完整窗口更新用图量。
- 每条流使用3个预先规定的随机mask规则；先在流内平均，再汇总3条观测流。
- 最多增加2域×3流×3mask＝18次ODR，首轮矩阵最多54次ODR，另有O与正确性试跑。
- 若两档G均不满足精度/覆盖条件或没有风险下降趋势，先总结原因，不自动扩展随机对照、阈值网格或种子。
- R是已知G更新量后的离线诊断对照，不声称部署时提前知道未来接受数。三个mask不是三个额外独立观测流。

G与V、R分别控制不同因素。首轮不能据这两种比较声称已经完全分离了“合法性过滤”和“几何质量评分”的贡献；必要的合法样本池内预算匹配等进一步归因，留在下一版验证设计。

本轮不自动增加单信号消融；只有用户审阅探索结果后，再决定是否拆分热图/残差/双头一致性，以及是否进入正式确认。

## 7. 指标、有效性与失败处理

主误差E采用固定HIL口径：hH旋转项＋hE归一化平移项；同步报告旋转度数、平移米数。保持现有原接受子集与拒绝前有限H数值的扩展口径分表；只有实际完整N/N才标all-samples。

对每条流，在固定开发评价ID清单中，先由O与A的可用预测确定参考集I_ref。该有效性规则不依赖G/V/E/R结果。所有方法的主风险与精度约束使用同一I_ref；不能取所有方法交集而删除新方法失败的困难图像。

对图像i定义D_i(m)=max(E_i(m)−E_i(O),0)。

| 指标 | 计算与作用 |
|---|---|
| 平均正退化量 | I_ref中所有D的均值，兼顾损害数量与幅度 |
| 严重退化 | I_ref中最大的ceil(0.05×样本数)个D的均值；包括零，不仅在退化图像中取5% |
| 严格负迁移率 | E_m>E_O的比例；另记录数值容差，避免把舍入误差当研究效果 |
| 平均位姿误差、旋转、平移 | 检查平均精度与保留收益 |
| 全开发集覆盖/失败转移 | 在完整约512个ID上报告可用数、原拒绝数、有效→无效和无效→有效 |
| 更新量 | 观察数、唯一图像数、接受/拒绝数、完整窗口数、实际用图数、尾部数 |
| 资源 | 总耗时、评分/几何求解/更新/评价分项、峰值显存、实际forward次数 |

完整开发集的可用预测数不得低于A；此外，候选若在I_ref中新增缺失预测，覆盖条件直接不通过，不能用其他图像新增有效预测抵消，也不能删掉这些ID后宣称风险降低。该方法在完整固定I_ref上的连续均值标记不可完整计算，缺失保留None；可附诊断值但不能代替主比较。基线参考集为空或风险地板为零时，单独说明不可比较或缺乏改善空间。

先逐流计算，再对3条流等权汇总。报告逐流配对差、均值和描述性波动；数千张图像及随机mask不能冒充独立实验重复。本轮不做正式显著性结论或事后补种子。

## 8. 探索性筛选规则

两域分别判断，不能用合并均值抵消某域退化。μ为同权重、本环境、同I_ref、3条流等权汇总的平均误差。

当A优于O时同时满足：
- μ_G ≤ 1.05 μ_A；
- μ_G ≤ μ_O − 0.8(μ_O − μ_A)。

当A没有平均收益时，不计算“保留80%”；要求G不劣于O，并报告G相对A的变化。约束使用未四舍五入数值，不使用论文值。

作为“值得追加诊断”的候选，还应满足：
- 覆盖条件通过；
- 两域平均D与严重退化指标均朝下降方向变化，不设最低百分比；
- 基线风险为零时要求不增加，标明没有改善空间，不硬算改善率。

两档都合格时，默认先最小化两域尾部D均值中的较大者，再比较两域平均D的等权均值；仍无法区分时优先75%设置。所有被比较设置均报告，不只展示最终选择。若指标各有取舍，列出取舍，不临时改主指标、阈值或容差制造“成功”。

加入R后，检查G相对E/V/R的配对趋势。若优势可由少更新或基本合法性过滤解释，限定结论，不宣称组合几何评分有独立贡献。

首轮结论用语限定为：
- 出现值得进一步验证的趋势；
- 有收益但约束/域间表现存在取舍；
- 未观察到有利趋势或原A缺乏可改善风险空间；
- 工程条件未通过，不能讨论效果。

正式确认的流数、区间方法、统计判断、扩样规则和最终成功标准均留待下一阶段，不能将3条开发流称为正式证明。

所有运行使用唯一run/log和独立screen，GPU串行，启动前查资源。保留原A/权重/参数/种子；已有通过且身份完全一致的证据可复用，不重复无关测试。

NaN/Inf、状态污染、全部接受不等价、数据/计数/重载/恢复不符、失败记录缺失时阻止后续。不能自动换种子、换参或重训。官方权重不可确认时不自行替换起点。

以前讨论的约1天是探索预算的规划参考，实际耗时由短试跑估计；不为用满预算加实验。若预计明显超出该规划，先报告原因与缩减选项，不把“不设每次耗时硬门槛”解释成无限计算授权。
